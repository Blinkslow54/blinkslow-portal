# Blinkslow Client Portal

Code for the client content portals at blinkslow.com/portal.

- `portal.js` reads the Blinkslow Client Portals Google Sheet and builds each client's portal.
- `portal.css` is the portal design.
- `logo.png` is the Blinkslow B mark.

Served with GitHub Pages at https://blinkslow54.github.io/blinkslow-portal/. The Webflow /portal page loads these files.

Content (deliveries, links, captions) lives in the Google Sheet, not here.
